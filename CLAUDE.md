# CLAUDE.md

Conventions and commands for working on this repo. Current state and next
steps live in `PROGRESS.md`. Read both before starting.

## What this is

A static web app (GitHub Pages, base path `/signLang/`) that turns Pakistan
Sign Language into English and Urdu text, entirely in the browser.
Pipeline: camera → MediaPipe landmarks → features → classifier (Web Worker) →
smoothing/segmentation → glosses → phrase lookup → English + Urdu.

## Hard rules

- **Real results only.** Never train on synthetic/random data and present it as
  working; never ship placeholder weights. Synthetic landmarks are allowed only
  in unit tests and must be named "synthetic". Report only measured accuracy,
  with the split and number of signers. Mark anything not run on a real device
  as untested.
- Video never leaves the device: no uploads, no analytics, no CDN at run time.
- Every asset URL must go through `assetUrl()` (respects `import.meta.env.BASE_URL`).
  Never write absolute `/x` paths.
- No COOP/COEP on Pages, so no SharedArrayBuffer: single-threaded WASM only.
- Feed MediaPipe the raw camera frame. Mirror only the *display* (CSS on the
  `<video>`). The model input must not depend on which camera is used.
- Every Urdu string starts `reviewed: false`; regenerate `docs/URDU_REVIEW.md`
  with `node scripts/gen-urdu-review.mjs` after changing Urdu text (CI checks it).
- Pin dependency versions exactly (`npm i -E`).

## Commands

```bash
npm ci                    # install (npm 10 crashes on some peer sets: use `npx npm@11.6.2 i -D -E <pkg>` to add packages)
npm run prepare-assets    # download .task models (SHA-256 checked) + stage WASM into public/rt/
npm run dev               # dev server at http://localhost:5173/signLang/
npm run build             # prepare-assets + typecheck + production build into dist/
npm test                  # Vitest unit tests (tests/)
npm run e2e -- --project=chromium-phone --project=chromium-desktop   # Playwright (needs a build)
node scripts/serve-dist.mjs   # serve dist/ like Pages under /signLang/; 404s logged; /__stats has byte counts
node scripts/bench-landmarks.mjs --seconds 20   # compare landmark pipelines in headless Chromium
node scripts/gen-urdu-review.mjs                # regenerate docs/URDU_REVIEW.md
```

WebKit is not installed in the dev VM; the `webkit-smoke` project runs only in
GitHub Actions. In this VM, Playwright's Chromium is preinstalled at
`/opt/pw-browsers`; `@playwright/test` is pinned to 1.63.0 to match. Do not run
`playwright install` here.

URL query overrides (before the hash): `?delegate=cpu|gpu|auto`,
`?detector=holistic|handpose`, `?diag=1`, e.g. `/signLang/?delegate=cpu&diag=1#/translate`.
`window.__psl.diagnostics()` and `window.__psl.lastFrame()` are exposed for tests.

## Layout

- `src/landmarks/` MediaPipe wrappers (`detector.ts`), hand side assignment (`hands.ts`), types.
- `src/pages/` one module per hash route. `src/i18n/strings.json` holds UI strings (en/ur/reviewed).
- `scripts/` build-time scripts. `scripts/models.json` pins model URLs + SHA-256.
- `public/rt/` and `src/generated/` are generated by `stage-runtime.mjs` (gitignored).
- `e2e/` Playwright specs; `e2e/fixtures/signer.mjpeg` is a CC BY 4.0 clip (see THIRD_PARTY.md).
- `docs/` DATASETS, URDU_REVIEW (generated), later FEATURES and EVALUATION.
- `training/` (milestone 3) Python pipeline.

## Style

TypeScript strict, no UI framework, plain DOM. Keep pure logic in small modules
with unit tests (`hints.ts`, `delegate.ts`, `hands.ts`, `env.ts`). Comments explain
*why*, especially anything measured (cite the number and how it was measured).
Commit in small steps; push the working branch at each stop.
